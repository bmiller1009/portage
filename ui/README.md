# ui

Minimal operational UI (React, TypeScript, Vite, TanStack Query) — a client of the public REST API, with no privileged UI-only backend (`docs/architecture/spec.md` §4.3, §32). Pages: Runs, Workloads, Environments, Datasets, Providers, Conformance, System.

Explicitly not built here: drag/drop DAG editors, a notebook editor, a large SQL IDE, BI visualization, or a workflow designer.

Not yet implemented — v0.2 milestone.
